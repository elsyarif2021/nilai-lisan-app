Deploy seluruh isi folder ke hosting HTTPS (misalnya Vercel atau Netlify). Buka URL, tunggu cache siap, lalu Pasang Aplikasi. iOS: Safari > Bagikan > Tambahkan ke Layar Utama. Data lokal tidak otomatis pindah dari file HTML lama atau browser lain. Ekspor cadangan sebelum berpindah. Untuk uji komputer: python -m http.server 8000 lalu buka http://localhost:8000. Jangan unggah data nilai siswa ke repositori publik.
V5: Upload XLSX atau CSV, pratinjau, lalu Tambahkan siswa. Kolom Nama Peserta/Nama Siswa/Nama. XLSX membutuhkan browser modern dengan DecompressionStream; CSV alternatif offline.
